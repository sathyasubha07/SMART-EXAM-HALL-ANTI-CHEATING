Algorithm Reference
// implementation details — exactly as used in this system
O(n) Time · O(1) Space
Fisher-Yates Shuffle
Produces an unbiased random permutation. Used to shuffle students before greedy allocation — ensuring fairness with no student-list ordering bias.
function fisherYatesShuffle(array) { const n = array.length; for (let i = n - 1; i > 0; i--) { // Pick random index j ∈ [0, i] const j = Math.floor(Math.random() * (i + 1)); [array[i], array[j]] = [array[j], array[i]]; } return array; }
O(1) Time · O(1) Space
CSP Constraint Check
Checks that placing a student at (row, col) has no same-department neighbor to the left or above — preventing forward-look conflicts in the greedy pass.
function isSafe(hall, row, col, student) { const dirs = [[0,-1], [-1,0]]; // left, up for (const [dr, dc] of dirs) { const [nr, nc] = [row+dr, col+dc]; if (nr >= 0 && nc >= 0) if (hall[nr][nc]?.dept === student.dept) return false; } return true; }
O(n²) Time · O(n) Space
Greedy Allocation
Iterates seats row-by-row. For each empty seat, picks the first student from the shuffled pool that passes isSafe. No backtracking — fast and practical for real exam halls.
function greedyAllocation(hall, students, rows, cols) { fisherYatesShuffle(students); // fairness first for (let r = 0; r < rows; r++) for (let c = 0; c < cols; c++) for (let i = 0; i < students.length; i++) if (isSafe(hall, r, c, students[i])) { hall[r][c] = students[i]; students.splice(i, 1); break; // greedy — no backtracking } return hall; }
O(1) Time · O(1) Space
8-Direction Graph Scorer
Checks all 8 neighbors. Direct neighbors score +3, diagonals +2. Final score maps to LOW / MEDIUM / HIGH risk — drives the heatmap and audit report.
const DIRS = [ {d:[0,1],w:3},{d:[1,0],w:3},{d:[0,-1],w:3},{d:[-1,0],w:3}, {d:[1,1],w:2},{d:[1,-1],w:2},{d:[-1,1],w:2},{d:[-1,-1],w:2} ]; function getRiskScore(hall, row, col, rows, cols) { const s = hall[row][col]; if (!s) return 0; return DIRS.reduce((sum,{d:[dr,dc],w}) => { const [nr,nc] = [row+dr, col+dc]; return (nr>=0&&nr<rows&&nc>=0&&nc<cols &&hall[nr][nc]?.dept===s.dept) ? sum+w : sum; }, 0); }
